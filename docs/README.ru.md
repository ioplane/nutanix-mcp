# Указатель документации

В этом каталоге находится каноничная документация nutanix-mcp.

Английская копия в [`en/`](./en/) — источник истины. Русская копия в
[`ru/`](./ru/) — перевод, синхронизируется в одном коммите с оригиналом.

| Тема | English | Русский |
|---|---|---|
| Обзор проекта | [`en/overview.md`](./en/overview.md) | [`ru/overview.md`](./ru/overview.md) |
| Архитектура | [`en/architecture.md`](./en/architecture.md) | [`ru/architecture.md`](./ru/architecture.md) |
| Быстрый старт | [`en/quickstart.md`](./en/quickstart.md) | [`ru/quickstart.md`](./ru/quickstart.md) |
| Эксплуатация | [`en/operations.md`](./en/operations.md) | [`ru/operations.md`](./ru/operations.md) |
| Конвейер поиска | [`en/retrieval.md`](./en/retrieval.md) | [`ru/retrieval.md`](./ru/retrieval.md) |
| Стратегия чанкования | [`en/chunking.md`](./en/chunking.md) | [`ru/chunking.md`](./ru/chunking.md) |
| Обучение и RAG | [`en/training-rag.md`](./en/training-rag.md) | [`ru/training-rag.md`](./ru/training-rag.md) |
| Гейт качества | [`en/quality-gate.md`](./en/quality-gate.md) | [`ru/quality-gate.md`](./ru/quality-gate.md) |
| Дорожная карта и спринты | [`en/roadmap.md`](./en/roadmap.md) | [`ru/roadmap.md`](./ru/roadmap.md) |

Все схемы оформлены на Mermaid и лежат рядом с тем документом, к которому
относятся. Источники Mermaid могут также храниться отдельными файлами в
`en/diagrams/` и `ru/diagrams/`.

Русские переводы делаются вручную. Обновляйте обе копии в одном коммите при
изменении содержимого.
